# Demo: a desk lamp

A small fictional dataset to try Kitting. No real company, supplier or price.

The desk lamp is made of a lamp base, an LED module and a shade. The base is a sub-assembly built in the
workshop from a steel plate and a switch. The lamp sells for 49.00 and its parts cost 17.60.

There are only 4 LED modules in stock, below their minimum order quantity of 10: plan a build of 5 lamps and
Kitting shows the missing LED module and proposes a purchase order.

Import the files from **Import / Export**, in this order: `suppliers.csv`, `parts.csv`, `assemblies.csv`,
`stock.csv`. Each import shows a preview first; confirm to write it.

For a larger example with variants, revisions, kits inside kits, serial numbers and a second supplier, see
[`examples/full/`](../full/).
